# Lester Faria — site pessoal

Site estático (portfólio/serviços) em React 19 + TypeScript + Vite 8 + Tailwind CSS v4.

## Comandos

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — typecheck (`tsc -b`) + build de produção
- `npm run lint` — `oxlint`
- `npm run preview` — serve `dist/`

Detalhes de arquitetura e convenções: ver `AGENTS.md`.
